## Entry

**Unfireable** — the one word that sums up the boss. Everyone has met one: the boss who survives every reorg, every complaint, every disaster, because nobody can fire him. The joke lands on its own, no caption needed.

## How it works

`main.ts` writes the entry word to `/output/entry.txt` (via `MAKEFUN_OUTPUT_DIR`, defaulting to `out`).

```sh
npx tsx main.ts
cat out/entry.txt
```
